# 曾志涛的个人面试准备系统

这是一个围绕个人履历、目标方向和长期能力建设持续维护的面试准备独立站，不绑定某一家公司或某一个岗位。当前包含 **855 道题卡、52 个实际分类，以及 21 张真实项目卡 + 19 张关联补课卡**，覆盖语音、多模态、端侧部署、生成式 AI、直播推荐与增长、模型训练推理、系统设计、Tech Lead 与算法基础。

首页按“个人准备台 → 简历专项 → 六条准备主线 → 全部知识库”组织。建议先读 [`知识脉络.md`](./知识脉络.md) 建立能力版图，再用 [`社招三轮面试策略补充.md`](./社招三轮面试策略补充.md) 做现场表达与轮次策略补充。

站点的主要学习入口已经升级为一套完整连续教程：**7 条学习主线、26 门课程、212 个章节**，52 个分类各自归属一门主课程，855 张题卡全部进入所属课程的章末练习。教程负责第一次系统学习，题卡继续负责复习、随机抽问和模拟面试。

| 学习主线 | 课程 |
|---|---|
| 个人项目 | 项目答辩与 Tech Lead |
| 语音主航道 | ASR、TTS、语音大模型 |
| 端侧与推理 | 端侧推理、OCR/深度、LLM 推理调度、推理评测 |
| 模型基础 | 分布式训练、Transformer、训练微调、RL 对齐、安全红队 |
| 多模态 | 多模态理解、生成式图像视频、多模态数据、世界模型与 Agent |
| 智能应用 | 搜索推荐、因果增长、RAG、Agent Workflow、算法系统设计 |
| 基础能力 | 两门算法手撕、模型手写、计算机系统基础 |

课程目录支持按主线、完成状态和关键词筛选；课程、章节可通过 Hash 深链接恢复，四级进度（章节、课程、主线、全站）均保存在浏览器本地。原有四门课程的进度会自动沿用。

## 使用方式

- **个人准备台**：查看能力版图、准备顺序、项目串讲与长期优先级。
- **连续教程**：第一次系统学习时从课程目录按主线推进；每章包含正文、具体例子、练习、检查点和关联题卡，前置课程只提示、不锁定。
- **简历项目**：默认只展示 21 张有简历原文依据的经历；10 张关联技术补课和 9 张通用方法分开查看，避免把没做过的知识说成项目。
- **全部知识库**：按分类检索和复习 855 道题卡，每题提供结构化讲解。
- 模拟模式先隐藏答案，点击“揭晓下一步”逐段查看，并配有 45 分钟计时器。
- “已掌握”进度保存在浏览器本地，不上传个人数据。

## 本地运行

项目无构建依赖。可以直接用浏览器打开 `index.html`，或启动任意静态服务器：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000/>。

运行测试：

```bash
npm test
```
