# 曾志涛的个人面试准备系统

这是一个围绕个人履历、目标方向和长期能力建设持续维护的面试准备独立站，不绑定某一家公司或某一个岗位。当前包含 **841 道题卡、51 个实际分类、40 道简历专项**，覆盖语音、多模态、端侧部署、生成式 AI、模型训练推理、系统设计、Tech Lead 与算法基础。

首页按“个人准备台 → 简历专项 → 五条准备主线 → 全部知识库”组织。建议先读 [`知识脉络.md`](./知识脉络.md) 建立能力版图，再用 [`社招三轮面试策略补充.md`](./社招三轮面试策略补充.md) 做现场表达与轮次策略补充。

## 使用方式

- **个人准备台**：查看能力版图、准备顺序、项目串讲与长期优先级。
- **简历专项**：围绕 ASR、TTS、端侧、实验可信度和 Tech Lead 打磨个人证据链。
- **全部知识库**：按分类检索和复习 841 道题卡，每题提供结构化讲解。
- 模拟模式先隐藏答案，点击“揭晓下一步”逐段查看，并配有 45 分钟计时器。
- “已掌握”进度保存在浏览器本地，不上传个人数据。

## 本地运行

项目无构建依赖。可以直接用浏览器打开 `index.html`，或启动任意静态服务器：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000/>。

运行测试：

```bash
npm test
```
